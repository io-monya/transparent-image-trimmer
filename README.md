# 画像 一括透明余白トリミングツール

画像の余分な透明余白（透過背景）を自動的に検出し、一括でトリミングするCLIツールです。  
macOSネイティブのFinderファイル選択画面が開き、いつも通り **Command(⌘) + クリック** や **Shift + 矢印キー** で複数画像をまとめて選択できます。

---

## 主な特徴

- 🖱 **直感的なファイル選択**: パスの手打ちは不要。Mac標準のファイル選択ダイアログが起動し、複数選択が可能。
- ⚡️ **高速・精密トリミング**: Node.jsの高性能画像処理ライブラリ `sharp` を採用。
- 📏 **パディング調整**:
  - `0px`（キワキワまでトリミング / デフォルト）
  - `5px`, `10px`, `20px` または **自由な数値指定**
- 🏷 **安全なファイル管理**:
  - 毎回 `元ファイル名_YYYYMMDD_HHmmss.拡張子` の形式でタイムスタンプを付加して `outbox/` に別名保存。
  - 同じ名前がすでに存在する場合は `_2`, `_3` の連番を付け、既存の出力を上書きしません。
  - 元画像は移動・変更・削除されず、そのまま残ります。
- 🖼 **幅広いフォーマット対応**: PNG, WebP, GIF, AVIF, TIFF などの透過画像に対応。アニメーションや複数ページ画像は、内容を失わないよう安全にスキップします。
- 🔎 **透過画像だけを処理**: 透過チャンネルのない画像は、絵柄を誤って切り取らないようスキップします。
- 🛡 **完全透明画像の自動スキップ**: 描画内容がない（全面透明な）画像は安全に検知・スキップしてサマリーで通知。

---

## 使い方

### 1. ツールの起動

ターミナルで本ツールのフォルダを開き、以下を実行します:

```bash
npm start
```

### 2. 操作の流れ

1. **ファイル選択ダイアログの表示**  
   Macの標準ファイル選択ウィンドウ（Finder）が開きます。  
   トリミングしたい画像を **Command(⌘) + クリック** や **Shift + クリック** で複数選択し、「開く」をクリックします。
2. **パディング（余白）の選択**  
   ターミナル上に選択肢が表示されます。矢印キーで選んで Enter を押します:
   - `0px` (デフォルト: 描画のキワキワまで詰める)
   - `5px` / `10px` / `20px`
   - 数値を自由に入力
3. **自動トリミング処理**  
   プログレススピナーとともに一括処理が実行されます。
4. **結果確認**  
   トリミング前後の解像度（例: `300x300 → 100x100`）や保存されたファイル名が表示され、結果は `./outbox/` フォルダに出力されます。

## フォルダ構成

```text
trimming_tool/
├── outbox/           # トリミングされた画像がタイムスタンプ付きで保存される場所
├── sample_images/    # 動作テスト用のサンプル画像（circle.png, empty.png, rect.webp）
├── src/
│   ├── index.ts      # メインCLIフロー・UI制御
│   ├── dialog.ts     # macOSネイティブダイアログ呼び出し (osascript)
│   ├── trimmer.ts    # sharpによる透過トリミング・パディング・完全透明チェック
│   └── utils.ts      # タイムスタンプ生成・拡張子判定等のユーティリティ
├── package.json
└── tsconfig.json
```
